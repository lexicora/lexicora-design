# lexicora-design

The design assets of [Lexicora](https://github.com/lexicora/lexicora-extension), a browser extension for capturing, structuring and searching what you read on the web.

> **This repository is archived.** Lexicora is no longer in active development, and these files are kept as a reference. Nothing here will change.

## Contents

| Path | What is in it |
| --- | --- |
| [`logo/`](logo) | The logo in all its variants, as SVG and PNG |
| [`icons/`](icons) | The extension's toolbar icons (16 to 128 px), with `dark/` variants |
| [`store/`](store) | Browser extension store graphics |
| [`brand/`](brand) | [Color palette](brand/color-palette.md) and [typography](brand/typography.md) |
| [`ui/`](ui) | The [shadcn/ui theme](ui/shadcn-theme.css) for Tailwind CSS v4, and [UI notes](ui/miscellaneous.md) |
| [`documentation/`](documentation) | [Brand guidelines](documentation/brand-guidelines.md) and [usage rules](documentation/usage-rules.md) |
